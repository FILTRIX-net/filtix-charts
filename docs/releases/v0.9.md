## Behavior and compatibility

The drawing package adds Fibonacci retracements, parallel channels and multiline text notes. Fibonacci level color and width inherit the drawing style when omitted; the default line style is solid. Native Objects controls can select hidden or locked saved drawings; one valid Apply creates one undo entry, invalid drafts remain editable, and streaming preserves focused input. Geometry locks prevent pointer edits while explicit API/style changes and deletion remain available.

OHLC Magnet snaps creation anchors and dragged handles using one indexed feed lookup; body translation remains free. Selection, previews, undo history and magnet mode are transient. The tools use the annotation Canvas and share projected geometry for rendering and hit testing. See the [drawing tools guide](../DRAWING-TOOLS.md).

`DrawingDocument` is version 2 and historical v1 documents migrate through the shared decoder. Terminal workspace remains version 4 with nested drawing v2; the historical `TerminalWorkspaceV4` shape retains nested v1. Migration is explicit on load/save and host storage keys do not change. Old packages cannot read new nested-v2 saves. See the [binding specification](../../SOURCE-DISTRIBUTION.md#omitted-development-materials) and [performance methodology](../PERFORMANCE.md#v09-advanced-drawing-workload).
