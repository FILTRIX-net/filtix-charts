# FILTIX Charts v0.8.0

Accepted 2026-09-13: **private local v0.8.0 release**. Implementation, functional checks, installed workloads, independent raw and documentation reviews, and actual visual inspection pass.

The terminal adds saved pane proportions, maximize/restore/reset, accessible resizing and a responsive study editor. Geometry changes preserve data, indicators, drawings and the viewport. In a short embed, the editor can temporarily focus the price chart while keeping the user's saved view intact.

## Public behavior

- Chart layout patches validate completely before committing. Getters return defensive committed snapshots; synchronous notifications describe committed changes. Pointer previews stay out of saved workspaces and are cancelled by authoritative geometry changes.
- Separators support pointer capture, ArrowUp/Down, Shift+Arrow and Home/End. Native Resize pane, Grow/Shrink, Maximize, View, Restore and Reset provide visible alternatives. Adjacent resizing and its read-only canResizePane query share the same geometry, including caller-owned neighboring panes.
- Terminal layout uses semantic pane IDs and keeps preferences for hidden studies and disabled volume. Defaults are price weight 1 / minimum 160 px, volume 0.26 / 64 px and oscillator 0.30 / 72 px. Reset preserves studies, drawings, market and data.
- Workspaces write version 4. Exact historical v1/v2/v3 documents migrate to default layout while retaining discoverable host storage keys. Version 4 requires every canonical pane exactly once.
- At host widths of at least 900 px the editor uses a right rail; taller narrow hosts use a bounded bottom region, and short hosts use a contained bottom sheet. Native fields and unchanged pane options retain focus, drafts and selection during streaming and mode changes.
- With the editor open, supported hosts of at least 320 × 360 px retain at least 96 CSS px of unoccluded price plot unless the user explicitly maximizes another pane. Temporary price focus is visibly explained and does not overwrite saved maximize. Smaller and zero-sized hosts remain finite and recoverable without an impossible readable-height guarantee.
