# FILTIX Charts v0.3.0 — editable studies

Status: accepted for the private local v0.3.0 release. All material implementation and measurement review findings are closed. Private local milestone, 2026-09-09.

The six-package cohort adds optional @filtix/drawings and a lazy generic primitive API. Four tools cover trend lines, horizontal price levels, rectangles and measurements, with endpoint/body editing, selection, styles, bounded undo/redo and validated versioned documents. The original /drawings.html study combines these with a keyboard-accessible inspector and explicit browser-local Save/Load.
