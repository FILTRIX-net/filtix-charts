# FILTIX Charts v0.7.0

Status: accepted private local release, 2026-09-12. Source, evidence and documentation reviews pass. The annotated local tag is `v0.7.0`; the measured source commit is identified below.

The optional terminal adds MACD and Bollinger Bands alongside SMA, EMA and Wilder RSI. MACD owns its line, signal and histogram in one oscillator pane. Bollinger owns a middle line, two boundaries and a native background band. The public indicator package exposes independent batch and streaming APIs; the band uses the existing Canvas scene.

## Public behavior

- MACD independently seeds fast and slow price EMAs; its signal EMA starts from finite MACD values. With 12/26/9 periods, MACD appears on input 26 and signal/histogram on input 34. Gaps restart warmup.
- Bollinger uses population standard deviation with a bounded centered window. Initialization is O(n log period), append/replacement O(log period); MACD is O(n)/O(1). Output histories remain O(n). Ordinary tails avoid retained-history scans and resource recreation.
- Reserve at most 8 stored studies, 3 combined RSI/MACD panes and 20 study series. All caps include hidden studies. Zero-opacity Bollinger fill keeps its reservation. Price and volume bring the maximum to 22 series / 5 panes.
- Native controls edit calculation/style fields, preserve focus during streaming and wrap inside a narrow container. Style-only changes avoid rehydration; calculation changes rebuild the affected visible group. Hiding releases actual resources while retaining settings.
- Workspaces export version 3. Strict v1/v2 migration preserves query/settings/drawings and host storage keys; v2 still accepts only its historical SMA/EMA/RSI variants. Invalid documents validate before transport, chart or identity changes.

See the [public API](../API.md), [terminal contract](../TERMINAL-CONTRACT.md) and [independent React example](../../examples/react-terminal/README.md). Use CSS to allocate the terminal's height. With an open editor and several oscillator panes, a short host leaves a compact price pane.
