# FILTIX Charts source distribution

This repository contains the FILTIX Charts source, tests, build configuration and user documentation under Apache-2.0. npm publication and hosted-demo availability are separate release steps. See docs/RELEASE-PROCESS.md for archive verification and publication.

## Omitted development materials

Internal work logs, machine-specific export manifests, implementation reviews and large historical measurements are retained separately from this public source distribution. Documentation links to omitted materials point here. Historical performance summaries describe their original workloads and do not establish performance of the current beta.

The five archived files under benchmark-results are the fixed browser parity test fixture (one manifest and four modules/maps), not the full historical evidence corpus. Source code and test behavior are unchanged by this documentation cleanup.
